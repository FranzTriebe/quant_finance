# Black-Scholes Model

Prices a European option with the Black-Scholes formula, using inputs you enter when running the notebook:

- volatility (decimal)
- current share price
- strike price
- interest rate (percent)
- maturity (years)

**Status:** work in progress. Input handling and the `d1`/`d2` calculations are written; the final price formula is not finished yet.

## Run

Open [`black_scholes_model.ipynb`](black_scholes_model.ipynb) in Jupyter and run all cells.
